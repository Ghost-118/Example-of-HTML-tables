# Example of HTML Tables

Proyecto enfocado en la estructuración semántica de datos numéricos e información académica mediante el uso de tablas en **HTML5**. El objetivo principal es organizar una lista de calificaciones finales de alumnos de Cálculo y presentar el promedio final mediante el elemento `<tfoot>`.

---

## 🚀 Características

- **Estructura Semántica Completa:** Uso de etiquetas `<table>`, `<caption>`, `<thead>`, `<tbody>` y `<tfoot>`.
- **Agrupación de Datos:** Presentación ordenada de apellidos, nombres y notas finales.
- **Resumen en Pie de Tabla:** Uso del atributo `colspan` para combinar celdas y mostrar el promedio general del grupo.
